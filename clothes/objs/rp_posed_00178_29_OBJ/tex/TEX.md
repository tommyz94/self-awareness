# `assets/mujoco/objs/rp_posed_00178_29_OBJ/tex/`

Texture maps for the `rp_posed_00178_29` avatar mesh.

Typical files in this folder:

- `*_basecolor.*` (preferred color texture)
- `*_normals.*`
- `*_roughness.*`
- `*_specular.*`

`e8` currently uses the color map (basecolor/albedo/diffuse) for MuJoCo rendering.
