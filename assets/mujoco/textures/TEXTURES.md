# `assets/mujoco/textures/`

Texture image assets loaded by the MuJoCo scene builders for room surfaces.

## Files

### `floor_wood_1.png`

Wood floor texture used by the two-room and corridor MuJoCo scenes.

### `wall_plaster.png`

Plaster wall texture used by the MuJoCo wall materials.

## Notes

- These files are static image assets, not generated output.
- The MuJoCo backend resolves them at runtime through the scene builder.
