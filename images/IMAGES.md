# `images/`

Static image assets for documentation or reports.

## Intended use

This folder is not used by runtime code. It is for:

- README screenshots
- report figures
- manually curated visual comparisons
- presentation assets

## Runtime capture behavior

Runtime observations are not written here.

- MuJoCo writes JPG observations directly to `outputs/.../obs/`.

If you want to keep selected screenshots for documentation, copy them from `outputs/` into this folder.
