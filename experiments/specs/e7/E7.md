# `experiments/specs/e7/`

Paper E5; public preset `paper/e5`. The bare numeric preset retains its historical auto-navigation defaults.

`e7` extends `e6` by adding random distractor cubes: same mirrored two-room
setup and moving humanoid distractors, plus `5..15` random colored cubes per
run.

## Contents

### `experiment.py`

Defines the `e7` experiment plugin. It:

- resolves the same widened mirrored two-room scene shape used by `e6`
- keeps random distractor count in `[1, 6]` and per-step distractor motion
- samples random cube count in `[5, 15]`
- samples cube/distractor/agent colors from the shared ten-color pool
  (duplicates allowed)
- with `e7_random_cube_heights=true` (default in `conf/experiment/e7.yaml`),
  each sampled cube becomes a vertical stack with random height in `[1, 5]`
  using same-color cubes one above the other; set
  `e7_random_cube_heights=false` to keep single-layer cubes
- samples cube positions on both room sides with in-room bounds and separation
  constraints
- marks cubes as reflectable (`reflect_in_mirror=true`)
- provides a dedicated MuJoCo scene builder with stack-capacity slots
  (75 real + 75 mirror)
- applies a dedicated reset applier that maps active cubes into slots and parks
  unused slots

## Notes

- `e7` uses the shared `explore_task` (non-cube task).
- `e7` defaults to `nav: auto`, `num_runs: 100`, and `max_steps: 100` through
  `conf/experiment/e7.yaml`.
- `save_dataset=true` works in `e7` exactly as in `e6` (same dataset schema).
