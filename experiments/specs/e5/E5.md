# `experiments/specs/e5/`

`e5` is a scene variation of `e1`: the same cube self-recognition task in the
mirrored two-room environment, but with colored humanoid distractor robots
added to the left room.

## Contents

### `experiment.py`

Defines the `e5` experiment plugin. It:

- resolves an `e5`-specific two-room mirrored scene with:
  - a wider centered mirror opening than the baseline room
  - the main agent on a rear row at `(-10.0, 0.0)`
  - six distractor slots on a nearer row parallel to the mirror
  - cube slots sampled from room-corner positions
- reuses the shared `cube_task`
- uses 30° turn actions (`a`/`d`) like `e1`/`e2`/`e3`
- builds per-run setup data with one main-agent color, random cube colors from
  the shared pool, per-distractor random colors (duplicates allowed), and a
  random distractor count in `[1, 6]`
- updates distractor robots at every ego-agent step using the same discrete
  action set (`w/s/a/d`) toward sampled waypoints; when a waypoint is reached,
  a new one is sampled
- provides backend overrides so MuJoCo renders distractors and their mirror
  reflections

## Notes

- `e5` randomizes distractor count per run in `[1, 6]`; the global
  `distractors` config knob no longer controls this experiment.
- `e5` honors `random_wall_color=true` by sampling one shared wall color per
  run; default remains the white wall material.
- Distractor slots are static in the scene template, while active distractors,
  their colors, and their waypoints are resolved per run.
- The `e5` mirror opening spans `z = -4.5 .. 4.5`, which is wider than the
  earlier half-wall opening.
