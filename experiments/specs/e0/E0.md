# `experiments/specs/e0/`

Plugin package for experiment `e0`.

`e0` is the direct mirror self-perception sanity check: the agent starts one
step in front of a wide, unobstructed mirror opening with no cubes or
distractors in the room. The task is to report its own body color immediately
from the visible reflection, without navigation.

## Files

### `experiment.py`

Defines the canonical `EXPERIMENT` plugin object for `e0`. It:

- resolves a mirrored two-room scene with:
  - direct-view spawn near the mirror plane
  - wide mirror window spanning the full room width
  - no cubes
  - no distractors
- randomizes the agent body color from the shared color pool
- uses the dedicated `self_perception_task`

## Notes

- `e0` is intended as a one-step sanity check rather than a navigation task.
- The Hydra preset in `conf/experiment/e0.yaml` fixes `num_runs: 10` and
  `max_steps: 1`.
