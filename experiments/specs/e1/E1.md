# `experiments/specs/e1/`

Plugin package for experiment `e1`.

`e1` is the baseline mirror-room cube task: the mirror is present, the scene
uses the standard two-room layout with 30° turn actions (`a`/`d`), and the task
is the shared `cube_task`. Cube and agent colors are sampled from the shared
15-color pool each run.

## Files

### `experiment.py`

Exports the canonical `EXPERIMENT` plugin object for `e1`.
