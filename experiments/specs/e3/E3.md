# `experiments/specs/e3/`

Paper E3; public preset `paper/e3`.

Plugin package for experiment `e3`.

`e3` reuses the mirror-room cube task with 30° turn actions (`a`/`d`), but
injects a misleading color into the prompt so the run initializer can measure
prompt-following versus visual grounding. Cube and agent colors are sampled from
the shared ten-color pool each run.

## Files

### `experiment.py`

Exports the canonical `EXPERIMENT` plugin object for `e3`.
