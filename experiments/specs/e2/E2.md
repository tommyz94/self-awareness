# `experiments/specs/e2/`

Paper E2; public preset `paper/e2`.

Plugin package for experiment `e2`.

`e2` reuses the standard two-room cube task but disables the mirror to create
the no-mirror control condition. Cube and agent colors are sampled from the
shared ten-color pool each run.

## Files

### `experiment.py`

Exports the canonical `EXPERIMENT` plugin object for `e2`.
