# `experiments/specs/e4/`

Plugin package for experiment `e4`.

`e4` is the corridor prototype: a checkerboard corridor scene paired with the
shared `corridor_task` behavior.

Each episode samples one latent variant with uniform probability:

- `mirror`: corridor closes at the center mirror wall (target `done@10`)
- `long`: corridor is open on the right side with a second active agent
  (target `done@20`)

Grid layout:

- mirror mode: `10` rows x `3` lanes (left half navigable, right half visual)
- long mode: `20` rows x `3` lanes (`10+10` across both halves)

The variant is written in run metadata (`e4_variant`, `expected_done_step`) for
post-hoc analysis.

For `e4`, actions are `w/a/d/done` (no backward):

- `w` = forward
- `a` = forward-left diagonal (yaw unchanged)
- `d` = forward-right diagonal (yaw unchanged)

Terminal-row decision rule:

- `done` ends run with success (if timing/row constraints are satisfied)
- `w`/`a`/`d` on terminal row end run immediately as failure
