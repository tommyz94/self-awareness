# `experiments/specs/e6/`

`e6` is the distractor-only variant of `e5`: same mirrored two-room setup and
moving humanoid distractors, but no cube objects in the run scene.

## Contents

### `experiment.py`

Defines the `e6` experiment plugin. It:

- resolves a mirrored two-room scene with the same widened mirror opening used
  by `e5`
- keeps the same distractor slot layout and per-step distractor navigation logic
- samples a random distractor count per run in `[1, 6]`
- samples random distractor colors from the shared 15-color pool (duplicates
  allowed)
- samples the ego-agent color from the same pool
- leaves cubes out of the run setup object list
- uses 30° turn actions (`a`/`d`)
- exposes MuJoCo backend overrides for distractor rendering and updates

## Notes

- `e6` uses the shared `explore_task` (non-cube task).
- `random_wall_color=true` is supported and excludes the current agent and
  distractor colors when sampling the wall color.
- the `e6` Hydra preset sets `nav: auto`, `num_runs: 100`, and `max_steps: 100`;
  the runtime auto controller sleeps 0.5s between steps for visual tracking.
- `save_dataset=true` (default `false`) exports a structured
  `Mirror_Video_Dataset/` tree with per-episode RGB frames and metadata JSON.
