# `experiments/specs/e8/`

Plugin package for experiment `e8`.

`e8` mirrors the `e5` room layout and distractor dynamics, but defaults the
body visuals to the clothed human-mesh mode (`body_style=clothes`) and changes
the task to exploration-based self-description from mirror evidence.

## Notes

- Task uses `self_description_explore_task`: explore until you can identify
  yourself in the mirror, then return a detailed appearance description.
- Layout, distractor count, and cube placement still follow `e5`, but cubes are
  now incidental scene clutter rather than the goal.
- The distinguishing change is visual embodiment: the ego agent, its mirror
  reflection, and distractors use clothed avatar meshes when available.
- If no usable avatar mesh is found under `clothes/objs/` (or the legacy
  `assets/mujoco/objs/` path), the backend falls back to the default humanoid
  visuals.
